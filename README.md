# Spok Belajar

Spok Belajar adalah aplikasi web edukasi interaktif untuk membantu siswa tunarungu berlatih menyusun kalimat sederhana secara bertahap. Fokusnya ada pada latihan berbasis kata, interaksi yang mudah diikuti, serta dukungan visual melalui preview bahasa isyarat.

## Untuk siapa?

- **Siswa**: masuk tanpa akun, langsung mulai latihan.
- **Guru/Admin**: mengelola materi latihan dan memantau hasil belajar.

## Alur penggunaan

### Siswa

1. Mengisi identitas singkat.
2. Memilih sesi/latihan yang tersedia.
3. Menyusun kalimat dari kumpulan kata (drag-and-drop atau tap/klik).
4. Melihat preview GIF bahasa isyarat per kata bila diperlukan.
5. Mengirim jawaban dan melihat hasil.

### Guru/Admin

1. Login.
2. Mengelola konten pembelajaran:
   - kategori
   - level
   - kata + media pendukung
   - latihan/soal
3. Melihat rekap/riwayat hasil latihan siswa.

## Fitur utama

- Landing page dengan jalur masuk terpisah untuk siswa dan guru/admin
- Latihan menyusun kalimat dengan **drag-and-drop** dan alternatif **klik** untuk aksesibilitas
- Preview GIF bahasa isyarat untuk membantu pemahaman kata
- Pencatatan hasil latihan agar progres bisa dipantau
- Dashboard admin untuk pengelolaan materi dan hasil belajar
